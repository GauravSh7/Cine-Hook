# India city directory attribution

`india-city-directory.json` is a searchable location directory, not a statement that CineHook has ticket inventory in each place.

- Source: GeoNames `cities1000` export and `admin1CodesASCII.txt` (`https://download.geonames.org/export/dump/`)
- Snapshot date: 14 October 2026
- Filter: India populated places, mapped to their GeoNames state/union-territory subdivision; duplicate names within a subdivision are collapsed.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0). GeoNames attribution and license: `https://www.geonames.org/export/` and `https://creativecommons.org/licenses/by/4.0/`.

This directory is used only to make location search broad. Actual showtimes, venues, and ticket availability continue to come from CineHook's own database records.
