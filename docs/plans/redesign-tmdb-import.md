# Manual development catalog import

The self-contained fixtures use original CC0 cinematic illustrations and no ratings. IMDb is neither scraped nor imported. Film title, language, runtime and theatrical release facts are referenced by each manifest entry; descriptions are original. Dates identify the listed theatrical market, not earliest festival premieres.

Optional command: `npm run catalog:import:tmdb -- --movie-id <exact UUID> --tmdb-id <exact positive provider ID>` from backend. The script is `tsx prisma/dev-tmdb-import.ts`. Set `NODE_ENV=development` and the server-only `TMDB_READ_ACCESS_TOKEN` locally. Never put that token in a VITE/frontend variable or commit it. The command verifies local `cinehook_dev` on PostgreSQL port 5432 before updates. It is not an application runtime dependency and never runs automatically.

Choose and verify the exact provider film ID manually. Matching title, original language, release year and returned ID must agree; invalid or failed responses preserve existing metadata. Requests time out after five seconds and reject redirects. Complete verified ratings expire after seven days, at which point public reads show no rating until a successful manual refresh. A failed refresh preserves stored data but does not make an expired rating visible. Cached complete rating tuples for the same exact provider ID avoid another request within that bounded lifetime. Missing images preserve existing original artwork; both valid provider images are required before replacing its attribution.

Provider artwork and ratings are optional and subject to TMDB's current licence and attribution requirements. Obtain the appropriate permission for the intended usage before importing. See [TMDB FAQ](https://developer.themoviedb.org/docs/faq) and [movie details API](https://developer.themoviedb.org/reference/movie-details). TMDB requires its approved logo and the notice “This product uses the TMDB API but is not endorsed or certified by TMDB.” in an About/Credits area; ensure that area is present before publicly publishing imported content. A free developer key is not a blanket commercial licence. No live import was performed for this delivery.
