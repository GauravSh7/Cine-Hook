# Operator-provided authorized media assets

This directory intentionally contains no TMDB logo. When authorized TMDB data is
configured, obtain an approved SVG from TMDB's official logos/attribution page
and save it as `tmdb-logo.svg` here before import/public use. Preserve its official
aspect ratio and colours. CineHook's About & media credits section loads that
asset for imported films. Do not put keys/tokens or a .env file in this public
directory. See `docs/provider-setup.md` for the complete private-key checklist.
